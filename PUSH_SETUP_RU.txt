ВАЖНО
ZIP содержит сайт, Service Worker и код Firebase Cloud Functions. Чтобы push работал, когда сайт свёрнут или закрыт, одного Netlify ZIP недостаточно: нужно один раз настроить FCM и опубликовать Cloud Functions. Пока это не сделано, нельзя считать push работающим.
Телефон, который полностью выключен, не может показать уведомление до включения.

ЧАСТЬ 1. Firebase Cloud Messaging (ключ VAPID)
1. Открой https://console.firebase.google.com/ и выбери fa-mogniy.
2. Нажми ⚙ Project settings → Cloud Messaging.
3. В Web Push certificates найди пару ключей. Если ключа нет, нажми Generate key pair.
4. Скопируй Public key.
5. В index.html найди FCM_VAPID_KEY и замени BHdXgYQY52XcTudt7AiDt-VSCKl0JI3GIl2VDlDQIXR2KHkufO-VpDbAokbMB1VUoZY-djkwyLuZOqO4eBSolZA на скопированный public key. Не вставляй private key и не публикуй его.
6. Загрузи в Netlify файлы index.html и firebase-messaging-sw.js в корень сайта (не папку внутри сайта).

ЧАСТЬ 2. Опубликовать отправку push
Cloud Functions отправляет push при новом сообщении в личном чате или группе. Это нужно запускать из папки, где лежит каталог functions.
Требуется Node.js 20+ и Firebase CLI; для Cloud Functions проекту обычно нужен тариф Blaze (возможна оплата за использование). Не включай биллинг, если не понимаешь условия — попроси взрослого помочь.

Команды в терминале:
  npm install -g firebase-tools
  firebase login
  firebase use fa-mogniy
  firebase deploy --only functions

Перед deploy в корне локального проекта должен быть .firebaserc:
  {"projects":{"default":"fa-mogniy"}}
и firebase.json:
  {"functions":{"source":"functions"}}

Если Firebase CLI спросит регион, выбери тот же регион, где находится Realtime Database. Если деплой не проходит, не меняй правила базы на публичные — пришли текст ошибки.

ЧАСТЬ 3. Проверка
1. На телефоне открой сайт в Chrome через HTTPS.
2. Войди в аккаунт, открой Профиль/Настройки и включи 🔔 Уведомления.
3. Разреши уведомления браузера. Если появляется сообщение о недостающем VAPID key, проверь Часть 1.
4. Войди во второй аккаунт на другом устройстве и отправь тестовое личное сообщение или сообщение в группу.
5. Сверни/закрой сайт на первом устройстве. После успешной настройки FCM и Functions push должен прийти и без открытой страницы, если браузер/Android разрешает фоновые уведомления.

БЕЗОПАСНОСТЬ
- Не меняй Firebase Rules на публичные.
- Не удаляй существующие данные пользователей/чатов/групп.
- Не публикуй приватные ключи. VAPID public key предназначен для клиентского кода.
